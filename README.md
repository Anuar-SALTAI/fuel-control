# Fuel Control

Жеңіл Streamlit қосымшасы: автокөліктердің кез келген кезеңдегі жанармай шығынын қазақша немесе орысша есептеу, тарихын Supabase-та (немесе жергілікті SQLite-та) сақтау және Excel-ге экспорттау.

## Мүмкіндіктер

- бірнеше автокөлік және әрқайсысына жеке жазғы/қысқы норматив;
- бастапқы **Газель** нормативтері: жазда 26, қыста 29,12 л/100 км;
- жүрген қашықтық = соңғы одометр − бастапқы одометр;
- нормативтік шығын = жүрген қашықтық × норматив / 100;
- есептік қалдық = бастапқы қалдық + құйылған жанармай − нормативтік шығын;
- еркін күндер аралығы, опционалды нақты қалдық, үнем немесе артық шығын және Excel экспорт;
- Android және iPhone экрандарына бейімделетін Streamlit интерфейсі.

## Жергілікті іске қосу

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Деректер әдепкіде `data/fuel_control.db` файлында сақталады. Басқа жолды `FUEL_CONTROL_DB` орта айнымалысы арқылы беруге болады.

## Supabase баптауы

1. Supabase жобасын ашып, SQL Editor ішінде `supabase/schema.sql` файлын орындаңыз.
2. Authentication → Providers бөлімінде Email провайдерін қосыңыз. Қажет болса,
   **Confirm email** параметрін қосыңыз; қолданба тіркелген адамға растау хабары
   жіберілгенін көрсетеді және растауға дейін сессия ашпайды.
3. `.streamlit/secrets.toml` файлын жасаңыз (оны Git-ке қоспаңыз):

```toml
SUPABASE_URL = "https://your-project.supabase.co"
SUPABASE_ANON_KEY = "your-anon-key"
```

Осы екі secret бар кезде қолданба Supabase Auth арқылы кіруді талап етеді және RLS
арқылы әр пайдаланушының автокөліктері мен жазбаларын бөлек сақтайды. Secrets жоқ
болса, бұрынғыдай жергілікті SQLite автоматты түрде қолданылады.

## Streamlit Community Cloud

Репозиторийді жаңа қолданба ретінде қосып, entry point ретінде `app.py` таңдаңыз. Тәуелділіктер `requirements.txt` арқылы автоматты орнатылады. Community Cloud-та жергілікті SQLite файлы қайта іске қосылғанда жоғалуы мүмкін; тұрақты өндірістік сақтау үшін сыртқы сақтау қызметін пайдаланыңыз.
